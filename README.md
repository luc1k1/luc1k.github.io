# Rasul Eyvazli — Portfolio

Personal portfolio built with React, Vite and Framer Motion. Live at **https://luc1k.live**

## Development
```bash
npm install
npm run dev      # http://localhost:5173
```

## Editing content
- `src/data.js` — profile, contacts, experience, skills
- `src/projects.js` — projects (put images in `public/images/`)
- `public/Rasul_Eyvazli_CV.pdf` — CV for the "Download CV" button

## Deploy
Every push to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
